# AI Teams

نسخه اولیه وب اپلیکیشن چندعاملی برای ساخت تیمی از هوش مصنوعی‌ها.

## امکانات فعلی
- افزودن و حذف اعضای تیم
- تعریف نام و نقش هر هوش مصنوعی
- تعریف هدف پروژه
- اجرای ترتیبی اعضا
- نمایش گفت‌وگوی تیم
- ذخیره تنظیمات در مرورگر با localStorage
- خروجی JSON از تنظیمات
- رابط واکنش‌گرا برای دسکتاپ و موبایل

## اجرا
فایل `index.html` به‌صورت مستقل در مرورگر باز می‌شود.

## نکته امنیتی
این نسخه برای UI و تست جریان تیم ساخته شده و پاسخ‌ها را در حالت نمایشی تولید می‌کند. کلید API را داخل `index.html` قرار نده. برای اتصال مدل‌های واقعی، مرحله بعد باید یک backend/serverless function برای نگهداری امن کلیدها اضافه شود.

## انتشار آنلاین
ریپو برای GitHub Pages آماده است؛ در تنظیمات Pages، منبع انتشار را روی branch `main` و پوشه root قرار بده.

# AI Teams

نسخه وب چندعاملی برای ساخت تیمی از هوش مصنوعی‌ها.

## امکانات
- افزودن و حذف عامل‌ها
- تعریف نام، نقش و System Prompt برای هر عامل
- فعال/غیرفعال کردن اعضا
- تعیین Provider، Endpoint، مدل و API Key برای هر عامل
- حالت نمایشی بدون API
- حالت اتصال واقعی به APIهای سازگار با OpenAI Chat Completions
- اجرای ترتیبی تیم
- انتقال هدف و خروجی اعضای قبلی به عضو بعدی
- نمایش خطاهای هر مرحله بدون متوقف کردن کل تیم
- تست اتصال هر عامل
- ذخیره تنظیمات در مرورگر
- خروجی تنظیمات بدون API Key
- طراحی واکنش‌گرا برای موبایل و دسکتاپ

## اجرای آنلاین
این پروژه برای GitHub Pages آماده است و از `index.html` در شاخه `main` استفاده می‌کند.

## اتصال واقعی
برای هر عامل در حالت «اتصال واقعی» این موارد را وارد کن:
1. Endpoint
2. Model
3. API Key
4. System Prompt و Role

در اجرای واقعی، درخواست هر عامل شامل هدف تیم و خروجی اعضای قبلی است.

## امنیت
این نسخه برای تست شخصی از API Key در مرورگر استفاده می‌کند و کلیدها را داخل خروجی تنظیمات صادر نمی‌کند. برای یک محصول عمومی، کلیدها باید به backend یا serverless function امن منتقل شوند و از قرار دادن credential در کد سمت کاربر خودداری شود.

## ساختار فعلی
- `index.html`: کل رابط کاربری و orchestrator سمت مرورگر
- `README.md`: راهنمای پروژه

## مرحله بعدی پیشنهادی
افزودن backend امن، سیستم حافظه برای هر پروژه، اجرای موازی/شرطی، محدودیت توکن و هزینه، تاریخچه اجراها و امکان انتخاب مدل‌های مختلف برای هر مرحله.

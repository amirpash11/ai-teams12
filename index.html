ماموریت تیم

حالت نمایشی برای تست رابط و جریان همکاری است و بدون API کار می‌کند.
در حالت واقعی، AI Horde مستقیم و بدون کلید کار می‌کند؛ Providerهای دیگر از Gateway امن استفاده می‌کنند و کلیدشان داخل مرورگر ذخیره نمی‌شود.

راهنمای اتصال مدل

هر عضو می‌تواند مدل و endpoint مستقل داشته باشد. برای سرویس‌های سازگار با OpenAI از مسیر Chat Completions استفاده می‌شود.
نمونه endpoint: https://api.openai.com/v1/chat/completions
یا یک endpoint سازگار دیگر. نام مدل و کلید را در تنظیمات همان عضو وارد کن.
